# Raw sources — PSPO I / CSPO

Drop the original source materials you fed into NotebookLM here: PDFs, articles, book excerpts, links (as `.txt`/`.md` files with the URL), the Scrum Guide, etc.

These are the primary sources used for grounding generated PSPO I exam questions in real Scrum
body-of-knowledge content, alongside [notebooklm-exports/pspo](../../notebooklm-exports/pspo/).
Sibling exams (e.g. [`../pmp/`](../pmp/)) keep their own raw sources in their own subfolder — see
[`shared/exams.mjs`](../../../shared/exams.mjs) for the full per-exam directory mapping.
