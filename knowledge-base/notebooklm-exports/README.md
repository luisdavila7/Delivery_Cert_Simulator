# NotebookLM exports

Drop your Gemini NotebookLM-generated artifacts here, in a subfolder per exam (e.g. `pspo/`,
`pmp/`) matching the exam IDs in [`shared/exams.mjs`](../../shared/exams.mjs): Study Guide, FAQ,
Briefing Document, Mind Map text export, chat summaries, etc.

Any file format is fine (`.md`, `.txt`, `.pdf`, `.docx`) — these will be read during the content-ingestion phase to help ground that exam's generated questions in how you've personally conceptualized the material.
